# Nimbus Markdown for VS Code

Open a `.md` file and read it rendered as Nimbus, the same page the [browser extension](https://chromewebstore.google.com/detail/kbkjbpmegfjbnpkdmlelkemmolegipkk) shows in Chrome: Mermaid diagrams drawn by [Ondine](https://ondine.sh), math, syntax highlighting, a table of contents, and extended Markdown syntax.

## Features

- **Opens rendered:** Markdown files open as Nimbus by default, and update as you edit the source.
- **Switch to text:** use the button at the top right of the editor to show the plain text, and the same button to come back.
- **Themes:** the Nimbus, GitHub and other browser extension themes. Set `nimbusMarkdown.theme`, or leave it on `auto` to follow your VS Code color theme.
- **Extended Markdown:** abbreviations, attributes, definition lists, footnotes, inserted and marked text, subscript, superscript, and task lists.
